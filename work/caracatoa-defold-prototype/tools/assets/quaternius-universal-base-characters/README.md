# Selected Quaternius head and hair source assets

The source meshes in `base/` and `hairstyles/` are from Quaternius' **Universal
Base Characters** standard pack. The pack identifies itself as CC0 1.0 Universal;
the included `License_Standard.txt` is retained with these files.

Official source: <https://quaternius.com/packs/universalbasecharacters.html>

Caracatoa uses only these extracted source meshes to build its own skinned face,
eyes, eyebrows, and selected hairstyles. The output combines them with the
existing CC0 Quaternius Modular Character Outfits Fantasy bodies and original
Caracatoa class gear. The full source archive, paid source edition, shaders,
and unrelated pack content are not included.

Selected models: male/female full-body source meshes (head/neck triangles only),
`Hair_SimpleParted`, `Hair_Buzzed`, `Hair_Beard`, `Hair_Long`, and
`Hair_BuzzedFemale`. Base-color textures used by the generated client are kept in
`assets/models/quaternius/heads/`.

The pack creator requests attribution and support; this project credits
Quaternius even though CC0 does not require attribution.
